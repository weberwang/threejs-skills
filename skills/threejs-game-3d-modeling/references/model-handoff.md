# 静态模型交接

本交接资料连接几何建模与现有模型管线中的贴图、绑定动画、场景接入和 QA 工序。它属于当前 Work Item 的模型报告与文件证据，不引入新状态或下游确认阶段。

| 交接项 | 建模方记录 | 下游处理边界 |
| --- | --- | --- |
| 身份与来源 | 资源 ID、候选/版本、只读源 `.blend` 路径、运行模型的正式 GLB 路径，或仅烘焙背景时最终图片路径、对象/Collection、参考来源和许可。 | 按实际路径及候选身份绑定输入，不按“最新”或文件名猜测。 |
| 坐标与几何 | 运行模型记录 glTF 米制/Y-up、前向轴、原点/Pivot、变换、拆件边界、对象/网格、导出范围和修改器/三角化策略；烘焙源记录工作项冻结的场景与相机约定。 | 运行模型以下游实际交付的 GLB 为几何基准；烘焙背景以对应 `.blend` 源和最终图片路线为准。改变顶点、拆件、法线或导出策略时回到建模责任人复核。 |
| 拓扑与法线 | 实际拓扑检查结果、顶点/三角面数和统计口径、法线/切线策略、已知例外。 | 不将材质或光照问题直接归因到几何；结构或法线不符合规格时退回建模处理。 |
| UV 与槽位 | 实际 UV 通道名和用途、岛的位置/边界报告、接缝、允许重叠、需要时的拉伸/密度/Padding 结果；材质槽名、顺序、面分配及材质槽到纹理集的映射。 | 贴图制作者使用已交付 UV、槽位和纹理集映射。本技能不生产 PBR 贴图；未经几何负责人同意不得重展 UV、改变槽位或重分面。 |
| 高低模与 Cage（按需） | 记录高模、低模与 Cage 的对象/文件对应，投射距离与方向、隔离/匹配规则、法线和三角化约定；交付 Cage 的实际路径与候选版本。 | 仅在烘焙需要时创建这些输入；下游只读使用已交付 Cage，不得修改或覆盖。输入变化时回到建模责任人更新版本并复核。 |
| LOD 与碰撞 | 需要时记录 LOD 网格、每级实际预算/阈值/轮廓保留、该级 UV 与纹理图集的共用策略，以及碰撞代理身份、形状和数量；不适用项说明原因。 | 场景/玩法接入验证其真实用途；不把碰撞代理并入外观模型或烘焙输入。 |
| 骨架与变形前置 | 若资产预期后续绑定，注明关节区域拓扑、顶点顺序等几何约束；尚未实现的骨架、权重和动作明确标为下游工作。 | 绑定与动画由现有模型管线负责；需要改拓扑、顶点顺序或变形几何时退回建模。 |
| 预算与检查 | 目标视角/观看距离、结构基线、实际预算、未解决问题、适用的 GLB 回读和静态清单检查结果、人工检查候选与反馈。 | 区分模型资源技术事实、人工视觉意见与正式运行消费证据。 |

只有真实适用时才创建高模、Cage、额外 UV、多个 LOD 或碰撞代理。不完整或仍处于 blockout 的几何不能交给下游当作正式模型。贴图、动画或场景修改者不得把派生几何写回正式 GLB；任何修改均在获准路径内生成版本化派生结果，并在当前 Work Item 内回交模型负责人。

## 变更后的复查范围

| 变更 | 至少复查的受影响内容 |
| --- | --- |
| 形体、顶点、拆件、修改器或三角化 | 对运行模型复查 GLB 导出对象、几何/预算统计、法线、实际 UV 和回读；烘焙源复查实际烘焙输出及依赖该拓扑的下游资源。 |
| 法线、切线或硬边 | 运行模型复查导出后的法线和 GLB 回读；烘焙源复查受影响的最终图片呈现。 |
| UV、材质槽或面分配 | UV 实际位置和目标、材质槽到纹理集映射及贴图/槽位绑定；复查受影响的烘焙、绘制、打包、材质绑定，以及适用的运行 GLB 或最终图片路线。 |
| LOD 或碰撞代理 | 对应网格预算、切换阈值、每级 UV/图集共用策略及受影响的烘焙、绘制、打包、材质绑定；碰撞变化复查玩法空间与物理交互。 |
| 仅变更路径、候选身份或资源登记 | 模型清单路径、来源证据及适用的 GLTFLoader/运行引用或最终图片路径。 |

复查跟随真实依赖，不因局部修改重跑无关工序。问题回交时提供候选与文件路径、对象/网格/UV/槽位定位、预期与实际结果、受影响消费者和复现证据。
